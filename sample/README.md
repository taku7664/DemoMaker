# 보기

템플릿으로 실제 데모를 한 편 만들면 어떤 모습이 되는지 보여 주는 폴더입니다. 파일을 그냥 열면
동작하므로, 새 데모를 만들기 전에 먼저 열어 보고 어디까지 채워야 하는지 가늠하는 데 쓰십시오.

| 파일 | 바로 열기 | 바탕이 된 템플릿 | 왜 필요한가? |
| --- | --- | --- | --- |
| `그래프 로딩 UX 개선.html` | [▶ 열기](https://taku7664.github.io/DemoMaker/sample/%EA%B7%B8%EB%9E%98%ED%94%84%20%EB%A1%9C%EB%94%A9%20UX%20%EA%B0%9C%EC%84%A0.html) | `shared/templates/demo-compare.html` | 여는 동안 멈춘 것인지 기다리는 것인지 가를 수 없어, 창을 닫고 다시 여는 사람이 생긴다 |

「바로 열기」 는 GitHub Pages 로 올라간 같은 파일입니다. 저장소에서 HTML 을 눌러도 코드만 보이기
때문에, 받지 않고 만져 보려면 이 링크로 들어가야 합니다.

규격은 `shared/reference/STYLE.md` 에 있습니다.
